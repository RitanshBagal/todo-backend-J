Core Capabilities

Designed with modern architecture patterns and developer-first principles.

End-to-End Task CRUD

Create, inspect, update, toggle, and delete tasks instantly with real-time UI synchronization and validation safeguards.

Real-Time Search & Filters

Debounced instant search over title and description fields with multi-state filter tabs (All, Pending, Completed).

Dark / Light Mode

Seamless theme switcher with local storage persistence and system preference detection with zero page flash.

Jenkins Automated CI/CD

Declarative Jenkinsfile pipeline handling unit testing, quality gates, artifact build, Docker packaging, and container launch.

Thread-Safe In-Memory Store

Concurrent data structures for non-blocking task creation, status toggles, atomic ID generation, and thread safety.

Strict Validation & Errors

Jakarta validation annotations with standardized JSON error payloads, timestamping, and HTTP response codes.

Modular components designed for high performance, maintainability, and clean code.

REST API Reference

Explore available backend endpoints ready for integration.

Live JSON Endpoint
Method Path Description
GET /api/todos Get all todos (supports ?completed=true|false & ?search=text)
GET /api/todos/{id} Retrieve single todo details by ID
POST /api/todos Create a new todo task with validated JSON payload
PUT /api/todos/{id} Update an existing task's title, description, or status
PATCH /api/todos/{id}/toggle Toggle completion state atomically
DELETE /api/todos/{id} Delete specific task by ID
DELETE /api/todos Batch delete all tasks from memory store
